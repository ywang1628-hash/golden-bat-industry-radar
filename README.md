# 金蝙蝠2号 · 行业信号云图（独立版）

从金蝙蝠2号精简投研平台独立提取的行业云图模块，只包含信号行业统计，不包含账户、持仓、成交与收益模块。

## 文件

仓库仅2个文件：`index.html`主网页，以及本使用说明。网页内嵌HTML/CSS/JavaScript和历史信号数据，无需安装依赖、构建或依赖原投研平台。

## 功能

- 30M标准范式前五行业排名，点击行业查看对应股票。
- 默认展开云图：30M标准范式、30M纯拐头、30M调出，下拉切换。
- 日/周/月历史观察；近一周以最近5个已确认交易日计，缺资料不补零。
- 全部行业/所选行业的标准范式、纯拐头、调出每日信号折线，下拉切换并可隐藏。
- 逐日云图、行业数量对照、月度观察、股票信号明细与CSV导出。
- 股票按钮可独立查看代码、名称、申万一级行业、信号原文及已收录历史，不需要主平台。

面积按股票×资料交易日信号次数统计，颜色在每张图内部相对归一化，集中度高红、低绿。红绿不是价格涨跌或资金流。调出单独统计，1D不计入当前云图。

## 数据版本

- 18524条内嵌去重资料记录。
- 覆盖2026-07-01至2026-10-21，共60个已收录信号资料日期。
- 日期有缺口；截至10/21，不代表已加入10/27信号。
- 日期为资料使用交易日，实际触发交易日或时分以源资料为准。
- 本版沿用原始信号数据，未重新联网核验全部历史行业归属。

## 如何使用

下载仓库，浏览器直接打开`index.html`即可查看。公开仓库不等于已开通在线网页，在线访问需另行启用GitHub Pages或其他静态托管。

## 更新数据与接口边界

当前数据位于HTML中的`const DATA = [...]`，为静态内嵌数组；没有自动抓取钉钉、行情或后台历史的服务。新增信号可由开发人员更新该数组并重新发布。

现有记录字段主要为`date,code,name,industry,signal,tag`：date资料使用交易日，code六位字符串，industry申万一级，signal保留原文，同股同日多信号合并。未来API接入需先实现数据校验、股票×资料日去重、交易日历及缺失日期，再替换前端数据源并重绘。当前版本尚无通用远程JSON配置入口。

本独立版不附波形服务，也不将信号数量解释为收益。需要波形时应另接对应股票和30M周期的授权图表URL。
